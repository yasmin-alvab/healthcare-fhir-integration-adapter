# healthcare-fhir-integration-adapter
Repository to register activities executed for the FHIR Adapter project. 

### Analysis of FHIR R4 Standard
- Performed a deep dive into FHIR R4 Profiles, Data Models, and Data Structures required for client integration.
- Analyzed FHIR R4 Implementation Guides.
- Analyzed data standards for DEMIS (Deutsches Elektronisches Melde- und Informationssystem für den Infektionsschutz) to electronically transmit mandatory infectious disease reports, specifically for COVID-19.

### Design
- Proposed and designed a web solution using ASP.NET Core Web APIs and the MVC architecture pattern.

### Development
- Deployed the required components to the SAP BTP environment using Kyma runtime.
- Created data models equivalent to the FHIR R4 Profiles.

### Testing
- Tested data format conversion from the client front-end to the FHIR Adapter back-end.
- Tested the network connectivity and data exchange with DEMIS servers.
- Validated disease reports sent to DEMIS servers along with their corresponding validation responses.

### Workshop
- Participated in an on-site brainstorming workshop in Berlin, Germany (Feb 2023), conducting in-depth sessions on SAP BTP technology benefits and collaborating with cross-functional service providers to define innovative solution capabilities for the client.
